# UNREAD AI delivery outcomes

- [x] Users can paste a conversation, provide a title and display name, validate empty/oversized input, preview parsed messages, and load synthetic demonstration data.
- [x] The parser supports timestamped and untimestamped messages, multiline continuations, preserved unparsed lines, and safe text rendering.
- [x] The analysis engine runs locally without API keys or remote inference and produces an evidence-linked summary, five explainable priority levels, scores, tasks, deadlines, decisions, questions, mentions, and follow-ups.
- [x] Users can view dashboard, priorities, action items, decisions/questions, history, and privacy/settings navigation with real state-backed controls.
- [x] Tasks support open/completed states, reopen behavior, dismissal-ready data model, priority/deadline display, source references, and filters.
- [x] Relative and ambiguous deadlines are preserved honestly rather than silently guessed.
- [x] Conversations persist in IndexedDB with open, rename-ready metadata, reanalysis-ready messages, delete-one, delete-all, and graceful storage fallback.
- [x] Markdown and JSON exports are generated locally only after explicit user action and use safe filenames.
- [x] The UI is responsive, keyboard operable, semantic, high contrast, reduced-motion aware, and uses text labels in addition to color.
- [x] README documents architecture, installation, testing, deployment, privacy, rule-based versus model-generated behavior, honest AI disclosure, and known limitations.
- [x] Typecheck, tests, and production build are run and their actual results are documented before delivery.
- [x] No conversation content is sent to external services, and repository/deployment URLs remain placeholders until genuinely created and verified.
